Two words

Input: Information sent into a computer.

Variable: A named place in a program that holds a value.

1 Read the program

price = int(input("Price: ")) quantity = int(input("Quantity: ")) total = price * quantity print("Total:", total)

input asks you to type a value. It receives text. int changes whole-number text into a number. The = sign stores the result under a name. The * sign multiplies. print shows the label and answer.

2 Watch the example

PriceQuantityCalculationOutput
343 × 4 = 12Total: 12

The program stores price as 3 and quantity as 4. It multiplies them and stores 12 in total. The last line displays that value.

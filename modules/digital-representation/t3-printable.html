Read binary numbers

Open the Student Activity from the "Read binary numbers" assignment in Google Classroom. Use these pages for the same explanation and practice. Record answers in that activity; do not complete a second worksheet or export an extra module report.

Two words

Bit: A single 0 or 1 used to store information.

Binary: A number system that uses only 0 and 1.

1 Read the place values

Place value8421
9 in binary1001
01100110

A 1 includes its place value. A 0 adds nothing. 9 = 8 + 1, so its four bits are 1001. For 0110, add 4 + 2 = 6. Ordinary numbers use digits 0 to 9; this is the decimal system.

Read the values from left to right as 8, 4, 2, 1. That rule makes 1000 mean 8. Without an agreed rule, a reader might treat 1000 as the ordinary number one thousand. Zeros at the start add nothing: 0011 = 0 + 0 + 2 + 1 = 3.

Picture size in bits

Learn the picture rule

A pixel is one tiny square in a digital picture. A bit is a single 0 or 1. Count pixels first: width × height. Then multiply the pixel count by the bits used for each pixel. These are uncompressed data counts without extra file information.

Watch the example

A 4 by 3 picture has 4 × 3 = 12 pixels. Each pixel uses 2 bits, so 12 × 2 = 24 bits. The first answer counts pixels; the second counts bits.

Try it together

Calculate a 5 by 4 picture using 2 bits per pixel. Write both multiplications in your Student Activity. Name the unit beside each answer.

Try it on your own

Calculate a 6 by 4 picture using 2 bits per pixel. Show the pixel count and total bits. Write one sentence explaining the result.

Check your calculation

Picture and sound data

Grade 9 · W01-C02

Open the Student Activity from the "Picture and sound data" assignment in Google Classroom. Use these pages for the same explanation and practice. Record answers in that activity; do not complete a second worksheet or export an extra module report.

1 Read the examples

Sample: One measurement of sound taken at one moment. Sample rate: The number of sound measurements taken each second.

Picture bits = width × height × bits per pixel. Mono sound bits = samples per second × bits per sample × seconds. These are uncompressed data counts, excluding extra file information.

Sound example: 4 samples per second × 2 seconds = 8 samples. 8 samples × 3 bits = 24 bits. The values are small models for learning the calculation.

Picture example: 12 pixels at 1 bit each use 12 bits. At 2 bits each they use 24 bits. Two bits allow four colours instead of two, but need twice the data.

Sound choice: reducing the sample rate reduces the data size but may lose faster changes in sound. Keep the duration and bits per sample fixed.

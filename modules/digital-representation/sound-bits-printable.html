1. See the bits

A sample is one measurement stored as a number. A bit is a 0 or a 1. A group of bits makes a code for a number. Bit depth means the number of bits used for each sample.

Two bits can label four values: 00, 01, 10, 11.
Three bits can label eight values: 000, 001, 010, 011, 100, 101, 110, 111.

More possible values let us describe smaller differences within the same signal range. Sample rate tells us how often we measure; bit depth tells us how precisely we can store each measurement. More bits per sample do not add more samples.

With three bits, how many different measurement values can we label? ____
Count the codes to check.

2. Count the bits

Three sample codes: 01 | 10 | 00. Every code has two bits. Zeros take space too.

2 + 2 + 2 = 6 bits.
3 samples × 2 bits per sample = 6 bits.

Three samples use two bits each. How many bits altogether? ____

All totals here count uncompressed sound data for one channel, excluding extra file information. We count bits, not bytes.

3. Practise counting

Total samples × bits per sample = total bits.

4 samples × 3 bits each = ____ bits. Hint: 3 + 3 + 3 + 3.
5 samples × 2 bits each = ____ bits. Hint: 2 + 2 + 2 + 2 + 2.

Draw a group of bits for every sample. Count the bits to check your multiplication. Ask for feedback and correct your answers.

4. Count a recording

First count all the samples. Then count their bits.

Worked example: 4 samples each second, 3 seconds, 2 bits per sample.
Step 1: 4 × 3 = 12 samples.
Step 2: 12 × 2 = 24 bits.

Your recording: 2 samples each second for 3 seconds, with 4 bits per sample.
Step 1: 2 × 3 = ____ samples.
Step 2: ____ samples × 4 = ____ bits.

Check the sample count with feedback first. Then use that count in the second calculation.

5. Make a comparison

Worked example: 3 samples × 2 bits = 6 bits. The same 3 samples × 3 bits = 9 bits. More bits per sample allow more measurement values but need more storage. The sample count and recording time stay the same.

Your turn: keep the same eight samples.
8 samples × 2 bits each = ____ bits.
8 samples × 3 bits each = ____ bits.

The extra bits allow: more samples each second / more possible values for each measurement / a longer recording. Circle one.

Explain: More bits per sample allow… but need…

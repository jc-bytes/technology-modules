Two words

Sensor: A part that detects a change, such as light or distance.

Threshold: The value where a program changes its response.

A model of a sensor

A real distance sensor measures a gap. Today the simulator buttons supply pretend readings: A = 17 cm, A+B = 18 cm, B = 19 cm. The rule is distance > 18. The display shows X above 18 cm and stays blank at 18 cm or below.

Open and build together

Open makecode.microbit.org. Choose Import → Import File and select G7_Distance_Start.hex. Open Blocks. The A and B events already set distance and call checkDistance. In define checkDistance, add if distance > 18 then show icon X, else clear screen. Use Logic, Variables and Basic. Run A, then B.

Add the boundary yourself

From Input, add on button A+B pressed. Inside it, set distance to 18 and call checkDistance from Advanced → Functions. Click A, A+B and B in the simulator. Wait for each result before the next test.

Two words

Threshold: The value where a program changes its response.

Follow the system

Import G7_Mandrake_Start.hex in MakeCode. The first simulator is the sender; use its buttons. A second simulator appears after you add a radio send block. It is the receiver. A = 17 cm, A+B = 18 cm and B = 19 cm. Both use radio group 7. Buttons model a distance sensor. Radio carries a message; the receiver shows a skull and plays a short tone for ALERT.

Build one branch together

In checkDistance, replace show icon X with radio send string ALERT. Keep distance > 18. The supplied on radio received message event checks for ALERT, shows the skull, and plays a 440 Hz tone for 200 ms. Test B on the first simulator and watch the second.

Complete CLEAR yourself

In checkDistance, replace clear screen with radio send string CLEAR. The supplied receiver clears its display and stops sound when it receives CLEAR. Test B, then A+B. The warning must disappear at 18 cm.

Record six trials

Two words

Test: A check to find out whether something works.

Feedback: Information about work that helps someone improve it.

Read useful feedback

Example: At 19 cm, the 200 ms tone was hard to notice. Make it last 500 ms, then test again. This feedback names a test result and one change. It does not change the distance rule.

Introduction

A table organizes facts. Its title describes the whole table. A row runs across and keeps one record together. A column runs down and holds one kind of fact. A header names a column. A cell is one box where a row and a column meet.

There are 3 columns and 3 data rows. Including the header row, there are 4 rows. The title is outside the grid.

Example: How many pots of Basil are there? Find the Basil row. Follow it to the Pots column. The cell contains 4, so there are 4 pots of Basil.

  1. Draw a line around the Pots column.
  2. Underline the complete Basil row.
  3. Circle the cell that shows where Fern is kept.
  4. Put a star beside the header that names the plants.
  5. How many columns are there? ______
  6. How many data rows are there without the header row? ______

Explain your choices to a partner. Compare them with the definitions above and correct any mistakes.

Practice

A new plant needs a new row. A new kind of fact, such as Colour, needs a new column. Keep each plant's facts on one row.

Worked record: "Mint has 3 pots by the Window." Write Mint under Plant, 3 under Pots, and Window under Place in the same row.

Now build these records. Rose has 5 pots on the Patio. Cactus has 2 pots by the Window. Use one value in each cell.

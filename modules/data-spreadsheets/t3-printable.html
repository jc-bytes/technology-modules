Two words

Row: A line of cells going across a table.

Column: A line of cells going down a table.

A cell address

A cell is one box in a spreadsheet. Its address has a column letter first and a row number second. B2 means column B, row 2. A row runs across. A column runs down.

Each number in this table counts students attending the activity on that day.

ABC
1ClubTuesdayFriday
2Art69
3Chess85
4Music47

In your Technology Notebook, write: "A cell address gives the column letter first and the row number second. B2 means column B, row 2."

Worked example

Find B2: start at column B and move down to row 2. The value is 6. It tells us that 6 students attend Art on Tuesday.

Name the Guided chart

Click the chart title. Replace it with Club minutes.

The title tells us what the whole chart shows.

Label the bottom axis

Click your chart. Choose Chart Design → Add Chart Element → Axis Titles → Primary Horizontal.

Click the new title at the bottom and type Club.

Club tells us what each column represents.

Label the side axis

Click your chart. Choose Chart Design → Add Chart Element → Axis Titles → Primary Vertical.

Click the new title at the side and type Minutes.

Minutes tells us what the numbers measure.

Start the scale at zero

Read the lowest number on the side axis. It should be 0, so every column starts from the same point.

If it is not 0, right-click the side numbers. Choose Format Axis → Axis Options → Bounds. Set Minimum to 0.

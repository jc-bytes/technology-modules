Choose a safe response

Grade 9 · W03-C02

Open the Student Activity from the "Choose a safe response" assignment in Google Classroom. Use these pages for the same explanation and practice. Record answers in that activity; do not complete a second worksheet or export an extra module report.

1 Read the examples

Phishing: A trick that uses a fake message to steal private information. Malware: Software made to harm a computer or steal information.

A threat can cause harm. A protection reduces the chance of harm. Read the clue, name the danger, choose a protection, and explain how it helps. Verify unexpected messages through the official school website or a trusted adult. Report suspicious messages to the teacher.

Ransomware: malware that locks files and demands payment. A backup is a separate saved copy that helps recover lost files. Brute-force attack: repeated password guesses. A long, unique password makes guessing harder. Multi-factor authentication adds another verification step to protect an account when a password is stolen.

Model: a fake drawing tool locks a student’s work and demands money. The clue is locked files plus a payment demand. This is ransomware. Tell the teacher so school IT can isolate the affected device and restore a clean backup. A separate backup helps recover the work; it does not stop the first infection.

Compare online risks

Grade 9 · W07-C01

Open the Student Activity from the "Compare online risks" assignment in Google Classroom. Use these pages for the same explanation and practice. Record answers in that activity; do not complete a second worksheet or export an extra module report.

Begin

Probability means how likely a harmful event is. Impact means how serious the harm would be. Rate each low or high using a fact. Frequent problems or an exposed weakness support high probability. Loss of private records or the only project copy supports high impact. A protected device with no important data can have low probability and low impact.

Worked example

A project file is deleted every week and has no backup. Probability: high, because deletion happens weekly. Impact: high, because the only copy can be lost. Protection: keep a separate backup so the work can be restored.

Try one together

A practice computer stays offline, contains no personal files and is reset daily. Together: rate probability and impact of losing important files. Give one fact for each rating.

2 Watch the repeated check

Select Player. Put Control: forever below go to x: 0 y: -100 in its green-flag stack. Place Control: if then inside forever. Put Sensing: touching Balloon? in the hexagonal space. The loop keeps asking the question. The blocks inside if run only when the answer is yes.

3 Catch the balloon together

Inside that if, connect Variables: change score by 1 → Looks: say Caught! for 1 seconds → Control: stop all. Click the green flag and move right until Player touches Balloon. The score becomes 1 and Player says Caught! The scoring loop stops. Click the green flag for another round.

4 Add the wall rule yourself

Inside the same forever, below the first if, add a second if touching Wall? then. Inside it connect say Try again for 1 seconds → go to x: 0 y: -100. Test by moving left until Player touches Wall. Keep the two arrow-key stacks separate.

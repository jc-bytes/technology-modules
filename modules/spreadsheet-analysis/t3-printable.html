Three calculations

A formula is a calculation that starts with =. A function is a ready-made calculation used in a formula.

  • SUM adds the numbers.
  • AVERAGE adds them, then divides by how many numbers there are.
  • MAX finds the largest number.

B2:B4 means B2, B3 and B4. The colon includes both ends and the cells between them.

In A12, type Total books. In A13, type Average books. In A14, type Largest count.

Enter the formulas in B12, B13 and B14. Use the book counts in B2:B4.

  1. Click B12. Type =SUM(B2:B4) and press Enter. It adds 2 + 4 + 6 and shows 12.
  2. In B13, enter =AVERAGE(B2:B4). The result is 4, because 12 ÷ 3 = 4.
  3. In B14, enter =MAX(B2:B4). The result is 6, the largest count.

Check: Click B12 again. The cell shows 12, while the formula bar above the grid shows your formula.

If the formula stays as text, remove any apostrophe before =. If you see an error, check the spelling, colon and both parentheses.

Two words

Formula: A calculation written in a spreadsheet.

Chart: A picture that shows data so it is easier to compare.

A conclusion uses evidence

A useful conclusion names a result and the exact values that support it.

Worked example

Model: Class C borrowed the most books, with 6. Class C borrowed 4 more books than Class A because 6 − 2 = 4.

Together

Guided: Class D borrowed ___ books, the largest count. Class D borrowed ___ more than Class A because ___ − ___ = ___.

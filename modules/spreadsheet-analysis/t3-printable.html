Two words

Formula: A calculation written in a spreadsheet.

Function: A ready-made calculation, such as SUM, that uses the numbers you give it.

What each formula does

A formula starts with =. SUM adds numbers. AVERAGE adds them and divides by how many numbers there are. MAX finds the largest. B2:B4 means every cell from B2 through B4.

Model cellFormulaResult
B12=SUM(B2:B4)12
B13=AVERAGE(B2:B4)4
B14=MAX(B2:B4)6

The Model sheet has 2, 4 and 6 books. The average is (2 + 4 + 6) ÷ 3 = 4 books.

Guided values in B2:B5: 3, 5, 7, 9. Practice values in B2:B9: 7A 4; 7B 8; 8A 6; 8B 10; 9A 12; 9B 8; 6A 6; 6B 10. These are book counts.

A column chart

Each column stands for one class. Its height shows how many books that class borrowed. The horizontal axis names the classes. The vertical axis counts books.

Worked example

On Model, select A1:B4. Choose Insert, then Column, then 2-D Clustered Column. Set the chart title to Books borrowed. Under Chart Design, choose Add Chart Element, Axis Titles. Name the horizontal axis Class and the vertical axis Books.

Class C borrowed 6 books. Its column reaches 6 on the books axis.

Together

On Guided, select A1:B5 and build the same chart type. Add the title Books borrowed and axis titles Class and Books. In A18 write: Class D borrowed 9 books.

Check the guided chart

Check four columns, a zero baseline, and the titles Books borrowed, Class and Books. Check Guided!A18 against the table. Save now. The Practice chart is for the next 90-minute class.

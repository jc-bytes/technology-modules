Build the button counter

6C uses this route in Week 10; 6A and 6B in Week 11. Button B reset is required.

A counter remembers a number

Open https://makecode.microbit.org. Choose Import, Import File, and open G6_Counter_Starter.hex from Classroom. Use Blocks and the simulator. The variable count holds a number. On start sets count to 0 and shows 0.

Watch button A

Watch the example: when A is pressed, change count by 1, then show count. One press changes 0 to 1. Together, open Input, drag on button A pressed, then put Variables change count by 1 and Basic show number count inside it. Press A twice and check 1 then 2.

Add your reset

On your own, add Input on button B pressed. Put Variables set count to 0, followed by Basic show number count inside it. This uses the same reset steps as on start. Press B and check 0.

Say your prediction after A, A, B, then compare it with the display. Explain aloud: Button B changes count to ___ because ___. The written five-step record comes next class.

Save an editable project

Name the project G6_Counter_Firstname_Lastname. Click Download and keep the .hex file. Import that saved file back into MakeCode and check that its blocks reopen.

A light reading chooses an output

A light sensor gives a number from 0 for dark to 255 for bright. Our threshold is 100. If the reading is less than 100, show a diamond. Otherwise, clear the screen. Exactly 100 uses otherwise.

Trace the display on paper

For 20 and 180, follow the true or false branch. Draw the Small Diamond or a blank 5 × 5 grid. Predict 99, 100 and 101 in the table before checking each comparison.

Watch a prediction

20 is less than 100, so the diamond shows. Together, compare 180 with 100: the screen clears.

Build your night-light

In MakeCode choose Import, Import File and open G6_NightLight_Starter.hex. It contains forever and pause 100 ms. Forever repeats the check. Keep pause at the bottom so each check has a short gap.

Watch: drag Logic if then else into forever. Put the Logic less-than comparison in its condition. Put Input light level on the left and 100 on the right. In then, add Basic show icon and choose Small Diamond. In else, add Basic clear screen.

Try one together

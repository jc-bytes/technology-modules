Two words

Event: Something that happens, such as a button click.

Variable: A named place in a program that holds a value.

How a screen map works

A screen is one view of an app. A button starts an action. A dropdown is a list of choices. A message displays information. A screen map shows the screens and the action that opens each one.

A variable keeps a value. selected_meal keeps the chosen lunch. If it holds Vegetables, the confirmation must say Your lunch is Vegetables.

Two words

Test: A check to find out whether something works.

Bug: A mistake that makes a program behave incorrectly.

Test a plan before building

Expected means what should happen. Actual means what your map says will happen. Trace the written event rows; you are testing a plan, not running a finished app. A test passes when these results agree.

Watch a library test

Test: click Start on Home. Expected: Choose Book opens. A faulty map sends Start back to Home. Actual: Home opens. Result: Fail. Fix the destination to Choose Book. Repeat the same test: Choose Book opens, so it passes.

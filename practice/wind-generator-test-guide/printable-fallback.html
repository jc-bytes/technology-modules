Find why we multiply

In Arduino IDE

The code converts the A0 count into volts. It then multiplies by INPUT_SCALE to estimate the voltage before the divider. Equal 10k resistors give a scale of 2.

Find INPUT_SCALE near the top of the sketch.

Check: For this bench divider, INPUT_SCALE is 2.

Help if you get stuck

If your teacher changes the resistor values, the code values and scale must change too. Do not keep a scale of 2 for a different divider.

const float R_TOP_OHMS = 10000.0;
const float R_BOTTOM_OHMS = 10000.0;
const float INPUT_SCALE = (R_TOP_OHMS + R_BOTTOM_OHMS) / R_BOTTOM_OHMS;

Follow the eight samples

In Arduino IDE

The program takes eight quick A0 samples and adds their counts. Dividing the total by 8 gives their average, which can reduce small jumps.

Find the loop that adds eight samples.

Check: The loop runs eight times before calculating voltage.

Help if you get stuck

These eight quick samples are inside one displayed reading. You still take the separate three-trial records later.

for (byte i = 0; i < 8; ++i) {
  unsigned int raw = analogRead(VOLTAGE_PIN);
  if (raw >= 1020) atAdcLimit = true;
  total += raw;
}

Follow counts into volts

In Arduino IDE

First divide by 8 for the average count. Then multiply by the reference and divide by 1023 to estimate A0 volts. Finally multiply by the divider scale.

Read the voltage calculation from left to right.

Check: The final value estimates source volts for the configured divider.

Help if you get stuck

This calculation assumes the checked positive DC input circuit and matching board reference.

voltage = (total / 8.0) * ADC_REFERENCE_V / 1023.0 * INPUT_SCALE;

Know what the display means

In Arduino IDE

0.00 is a near-zero estimate. It cannot tell an unplugged source from a stopped generator. ---- means a sampled count neared the ADC limit or the value exceeded the display format.

Help if you get stuck

The dashes are a warning from software, not electrical protection. An unsafe voltage can damage the board before code responds.

Understand the 100 ohm resistor

At the disconnected turbine

A 100 ohm resistor across the generator is a load: it uses some generated energy and may lower the voltage. A0 would still receive the full terminal voltage in that circuit. It does not protect A0.

Point to the two generator terminals in the meter drawing.

Check: The meter measures between those terminals. The measuring input needs its own checked interface.

Help if you get stuck

A load resistor also needs a suitable power rating. At 5 V, 100 ohms turns 0.25 watts into heat. Let your teacher choose the load and its rating.

Scale knob one

Inside loop(), immediately after the pot1 line

map() changes one number range into another. A reading of 0 maps to command 0; 1023 maps to command 57. A halfway reading gives roughly a halfway command.

Add the angle1 line.

Check: angle1 holds a command from 0 to 57.

Help if you get stuck

The first pair, 0 and 1023, describes the input. The final pair, 0 and 57, describes the output.

  int angle1 = map(pot1, 0, 1023, 0, 57);

Add the middle-up button

Inside loop(), after the knobs

++ adds one to the remembered command. The if limit check brings it back to 160 if it went above 160. write sends the bounded value. delay(20) waits 20 milliseconds.

Add this complete S3 block.

Check: Holding S3 raises middleAngle toward 160. It cannot keep increasing above 160 in this block.

Help if you get stuck

Both if statements need their own braces. The inner if checks a number; the outer if checks a button.

  if (digitalRead(S3) == LOW) {
    middleAngle++;
    if (middleAngle > 160) {
      middleAngle = 160;
    }
    motor4.write(middleAngle);
    delay(20);
  }

Explain the upper limit

In this guide

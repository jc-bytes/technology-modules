Code your robotic hand

Control the assembled hand

In this guide

An Arduino program reads three knobs and four buttons, then sends position numbers to five servo motors. A servo is a motor that moves toward a chosen position.

Find the three knobs and four buttons on the assembled model. Keep the model disconnected while writing code.

Check: You can point to all seven controls. Keep the existing wiring.

Prepare the buttons and starting commands

Inside setup(), after the attach lines

INPUT_PULLUP makes an unpressed button read HIGH and a pressed button read LOW with the checked wiring. write() sends a position command to a motor.

Add these lines inside setup(), after the five attach lines and before its closing brace.

Check: All four buttons use INPUT_PULLUP. Motor4 starts with middleAngle and motor5 with baseAngle.

Help if you get stuck

LOW means pressed for this program. Copy the capitals and underscore. The other three motors follow their knobs in loop(). Keep the board disconnected; startup movement still needs the teacher check.

  pinMode(S1, INPUT_PULLUP);
  pinMode(S2, INPUT_PULLUP);
  pinMode(S3, INPUT_PULLUP);
  pinMode(S4, INPUT_PULLUP);

  motor4.write(middleAngle);
  motor5.write(baseAngle);

Make knob one control motor one

At the start of loop(), inside its existing braces

analogRead stores the A1 knob reading in pot1. map changes its 0–1023 range into a 0–57 command stored in angle1. write sends angle1 to motor1.

Add these three lines in order.

Check: A1 supplies pot1, angle1 holds the scaled value, and motor1 receives angle1.

Help if you get stuck

map(pot1, 0, 1023, 0, 57) means turn a 0–1023 reading into a 0–57 command. Halfway input gives roughly halfway output. This is not a measured joint angle. Keep 0–57; do not use the full-range Sweep example. Add no second loop().

  int pot1 = analogRead(A1);
  int angle1 = map(pot1, 0, 1023, 0, 57);
  motor1.write(angle1);

Add the middle-up button

Inside loop(), after the knobs

if checks a condition. digitalRead(S3) == LOW means S3 is pressed. ++ adds one to middleAngle; the inner if caps it at 160 before write sends it.

Add this complete S3 block.

Check: Holding S3 raises middleAngle toward 160. It cannot keep increasing above 160 in this block.

Help if you get stuck

== compares values; = stores a value. > means bigger than. At 160, ++ first makes 161, then the limit sets it back to 160. Both if blocks need their braces. delay(20) waits 20 milliseconds. Keep the limit before write().

  if (digitalRead(S3) == LOW) {
    middleAngle++;
    if (middleAngle > 160) {
      middleAngle = 160;
    }
    motor4.write(middleAngle);
    delay(20);
  }

Add the middle-down button

Inside loop(), after the complete S3 block

-- subtracts one. The lower limit check sets the command back to 90 if it went below 90.

Add this complete S1 block.

Check: Holding S1 lowers the motor4 command toward 90.

Help if you get stuck

Keep the < sign here. It asks whether the command fell below the lower limit.

  if (digitalRead(S1) == LOW) {
    middleAngle--;
    if (middleAngle < 90) {
      middleAngle = 90;
    }
    motor4.write(middleAngle);
    delay(20);
  }

Add the base-down button

Inside loop(), after the complete S4 block

Test and record the three knobs

Test and record the four buttons

At the checked model, with the teacher

Each button should change one remembered command in one direction while it is held. Releasing it stops that button block from changing the command.

Try S1, S2, S3 and S4 separately within the checked range. Release each before trying the next. Add each actual response to the same test note.

Check: S1/S3 command motor4 in opposite directions; S2/S4 command motor5 in opposite directions. Your notes say what actually moved.

Help if you get stuck

Press only one button at a time. This program does not prevent opposing buttons being held together. Record physical direction from the real model. Stop for strain, a jam or heat and tell the teacher.

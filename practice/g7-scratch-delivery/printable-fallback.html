Deliver to three houses

First name: __________ Last name: __________ Grade: __________

Your goal: three deliveries

Make the package visit House 1, House 2 and House 3. Count one delivery at each house.

Read the example below. The package stops and the counter changes: 0 → 1 → 2 → 3.

Read the example

The green flag returns the package to Start, x −120, y 0. It waits one second. The package moves 40 steps to House 1 and counts one delivery. After a pause, it does the same at House 2 and House 3. You will build one block named deliver and repeat it three times.

Get your starter

Download the Scratch starter

Keep the file G7_Three_Houses_Starter.sb3 in Downloads.

Open the starter in Scratch

Open Scratch in another tab. Keep this guide open.

Choose File → Load from your computer. Select G7_Three_Houses_Starter.sb3 from Downloads.

Select the package

Click the Parcel sprite below the Scratch stage. Open its Code tab.

You should see the starting blocks in the code area.

Find the starting position

x is left or right. y is up or down.

Find the x and y boxes below the stage. Our Start is x = −120, y = 0. Every house is on the same level, y = 0.

Return to Start

Click the green flag.

Check: the package is at Start, x is −120, y is 0, and deliveries is 0.

These starter blocks reset the program. The one-second wait gives you time to see Start.

Find My Blocks

A custom block groups instructions under one name. We will name ours deliver.

On the left of Scratch, click the pink My Blocks category. Click Make a Block.

Name your block

Type deliver in the name box. Leave Run without screen refresh unchecked. Click OK.

Leave the new define deliver block separate from the green-flag script. It will hold the delivery instructions.

Move to the next house

Click the blue Motion category.

Drag change x by 10 under define deliver. Change 10 to 40.

Forty steps takes the package from Start to House 1.

Count the delivery

The deliveries variable stores the number of deliveries.

Click orange Variables. Drag change deliveries by 1 below the movement block.

If its dropdown shows another name, choose deliveries.

Pause at the house

Click orange Control. Drag wait 1 seconds below the counter block.

The pause makes each delivery visible.

Check that all three instructions are connected below define deliver.

Run one delivery

Click My Blocks again. Find the small deliver block.

Drag it below wait 1 seconds in the green-flag script.

Keep define deliver separate. The small block tells Scratch to run its instructions.

Watch one delivery

Click the green flag.

Watch the package return to Start, pause, then move to House 1. The counter should show 1.

Read the x box: −80. The y box stays 0.

If it does not work

No movement? Put the small deliver block after the reset wait. Wrong count? Keep change deliveries by 1 inside define deliver. Starts in the wrong place? Check go to x −120 y 0 above the small deliver block.

Add repeat 3

A loop repeats instructions.

  1. Drag the small deliver block away from the green-flag script. Keep it nearby.
  2. Click Control. Attach repeat 10 below the reset wait.
  3. Change 10 to 3.

The empty space inside repeat is where the repeated action goes.

Put deliver inside the loop

Drag the small deliver block into the empty space inside repeat 3.

Check the picture. Keep the separate define deliver script unchanged.

Now the loop runs the same delivery instructions three times.

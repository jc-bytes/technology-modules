Create the six named storage boxes

In the new test project · JavaScript

A variable is a named box that remembers a value. Two boxes hold pin names, two hold numbers, one holds a word and one holds true or false.

Help if you get stuck

Type each name exactly, including capital letters. DigitalPin.P0 means pin zero; DigitalPin.P1 means pin one. 0 is a number, "UNKNOWN" is a text word and false means not connected. MakeCode may hide starting values of 0 and false in Blocks. If an unused name disappears, open Variables → Make a Variable and create that name again.

let echoPin = DigitalPin.P1
let echoTime = 0
let distanceCm = 0
let stickStatus = "UNKNOWN"
let btConnected = false

Write the small sensor-reading function

In MakeCode · JavaScript, then Blocks

A function is a named group of instructions. This helper sends a tiny pulse on P0, then measures how long the echo on P1 lasts. Its answer is time, not centimetres.

Choose JavaScript. Below your existing code, type this function without deleting the variable setup or Bluetooth service. Then return to Blocks.

Check: A separate purple function stack appears. It is outside on start and outside forever.

Help if you get stuck

0 means trigger off; 1 means on. The waits are 2 and 10 microseconds. The return line gives back the echo time and stops waiting after 25000 microseconds. In Blocks, that return expression appears grey. It is expected. Keep the function named readUltrasonicDistance.

Check the function blocks

Type this sensor helper only. Keep the code already in your project.

function readUltrasonicDistance() {
    pins.digitalWritePin(trigPin, 0)
    control.waitMicros(2)
    pins.digitalWritePin(trigPin, 1)
    control.waitMicros(10)
    pins.digitalWritePin(trigPin, 0)
    return pins.pulseIn(echoPin, PulseValue.High, 25000)
}

Build the failed-reading branch first

In Blocks · forever → first if

An unusable echo must choose UNKNOWN. This test also catches 0 when no echo arrives.

Below the sensor call in forever, build the first if/else.

  1. Drag Logic → if/else below set echoTime. Add else with + if needed.
  2. Put Logic → or in the condition. Fill it with echoTime < 116 and echoTime > 23200.
  3. Inside then, add set distanceCm to 0, set stickStatus to the Text word UNKNOWN, then Basic → show string with ?. Leave the outer else empty for now.

Check: The first then contains exactly the failed-reading result. The next page fills its else.

Help if you get stuck

< means less than; > means greater than. OR means either test can select this branch. 0 here marks an unusable distance. It must not be sent as a real measurement.

Turn echo time into centimetres

In Blocks · the outer sensor if’s else

The sound travels out and back. Dividing its echo time by 58 estimates centimetres. Rounding keeps one decimal place.

Build the distance calculation inside the outer else.

  1. Add set distanceCm to inside the empty outer else.
  2. From Math, fit arithmetic blocks together to make echoTime ÷ 58, then multiply that answer by 10.
  3. Place that result inside Math → round. Divide the rounded answer by 10 and put the whole calculation in set distanceCm.

Check: The calculation reads round((echoTime ÷ 58) × 10) ÷ 10. An echo of 1177 gives about 20.3 cm.

Help if you get stuck

Build the sockets from the inside outward. For 20.293… cm: ×10 gives 202.93…, round gives 203, then ÷10 gives 20.3. Leave room below this calculation for the near/far check.

Build the nearby-object branch

In Blocks · first if’s else → distanceCm ≤ 30

A usable distance of 30 cm or less chooses NEAR and displays X.

Build NEAR inside a second if.

  1. Put Logic → if/else below set distanceCm, inside the outer else.
  2. Set its condition to distanceCm ≤ 30. Use the comparison dropdown to choose ≤.
  3. Inside this inner then, put set stickStatus to the Text word NEAR, then Basic → show icon with X, the No icon.

Check: NEAR is inside both checks. Keep the inner else empty for the next step.

Send the chosen word and distance

In Blocks · the two empty Bluetooth sending branches

A comma separates the result from the cm estimate. Write line ends the message for the website.

Fill the sender and add its repeating pause.

  1. In the UNKNOWN then, add Bluetooth → uart write line with the variable stickStatus.
  2. In its else, add another uart write line. Put Text → join in its value socket.
  3. Use join’s + for three inputs: variable stickStatus, a Text comma , and variable distanceCm.
  4. After the entire if btConnected, add Basic → pause (ms) 500, still inside forever.

Check: One message per reading: NEAR,20.3, FAR,40 or UNKNOWN.

Help if you get stuck

Use variable blocks for stickStatus and distanceCm; do not type those names as text. Put a comma with no spaces in the middle join input. Keep the pause outside the sending if.

Name the distance value

In MakeCode · Variables

A variable is a named place that holds a value. distanceCm will hold the latest distance in centimetres.

Create the variable distanceCm. If your project already has one clear distance variable, rename it to distanceCm.

Check: The Variables menu contains distanceCm.

Help if you get stuck

Choose Make a Variable in Variables. A rename should update its existing uses. Keep only one variable for the reading used in this rule.

Name the reading check

In MakeCode · Variables

readingValid will hold true or false. True means this reading passed your sensor’s checked validity test.

Create a variable named readingValid.

Check: The Variables menu contains readingValid.

Help if you get stuck

Find the repeating instructions

Check readingValid

In MakeCode · new if condition

A true-or-false value fits directly in an if condition. When it is true, the program follows the then branch.

Put readingValid in the condition of the new if block.

Check: The top decision reads if readingValid then.

Add the other path

In MakeCode · outer if block

Else is the path used when the if question is false. Here it handles an unusable reading.

Use the + control on the if block to add an else branch.

Check: The outer decision has then and else spaces.

Help if you get stuck

If + adds else if first, use the block controls until you have a plain else path.

Show an unusable reading

In MakeCode · outer else branch

A question mark is a visible warning that the measurement is unknown. This makes a failed reading different from a clear display.

Put Basic → show string "?" in the outer else branch.

Check: An unusable reading follows the ? path.

Help if you get stuck

This ? convention belongs to this guide. Have your teacher keep it consistent with the checked sensor validity test.

Add the distance decision

In MakeCode · outer then branch

The inner decision runs only after the reading is valid. This prevents an error value from being treated as a real distance.

Place a second if true then block inside the outer then branch.

Check: The second decision is nested inside the valid-reading path.

Help if you get stuck

Nested means one block sits inside another. Use the diagram to check its position.

Compare the distance with 30

In MakeCode · inner if condition

The sign ≤ means less than or equal to. It includes 30 itself.

Use a Logic comparison to make the inner condition distanceCm ≤ 30.

Check: The inner condition includes values below 30 and exactly 30.

Help if you get stuck

Show the near warning

In MakeCode · inner then branch

Add the far path

In MakeCode · inner if block

When a valid distance is not 30 or less, it is above 30. The inner else handles that case.

Add an else branch to the inner if block.

Check: The inner decision has a near then branch and a far else branch.

Clear the far display

In MakeCode · inner else branch

Clear screen turns off the LEDs. We use it only after the reading has passed the validity check and is above 30.

Put Basic → clear screen in the inner else branch.

Check: A valid distance above 30 follows the clear-screen path.

Help if you get stuck

Leave the question mark in the outer else. Clearing the wrong else would hide failed readings.

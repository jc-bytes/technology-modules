Write the small sensor-reading function

In MakeCode · JavaScript, then Blocks

A function is a named group of instructions. This helper sends a tiny pulse on P0, then measures how long the echo on P1 lasts. Its answer is time, not centimetres.

Paste the sensor helper below the code already in your project. Choose Blocks and find the separate purple function.

Check: The function is its own stack. Its return expression may appear grey, which is expected.

Help if you get stuck

0 means trigger off; 1 means on. The waits are 2 and 10 microseconds. The return line gives back the echo time and stops waiting after 25000 microseconds. In Blocks, that return expression appears grey. It is expected. Keep the function named readUltrasonicDistance.

Add this entire function at the bottom of the JavaScript. Keep the existing lines.

function readUltrasonicDistance() {
    pins.digitalWritePin(trigPin, 0)
    control.waitMicros(2)
    pins.digitalWritePin(trigPin, 1)
    control.waitMicros(10)
    pins.digitalWritePin(trigPin, 0)
    return pins.pulseIn(echoPin, PulseValue.High, 25000)
}

P0 sends the short trigger pulse. P1 measures the returning echo. The answer is microseconds, not centimetres.

Help if you get stuck

An event runs when the connection changes. true means connected; false means disconnected. These events remember the connection while forever reads the sensor.

Add both events at the bottom, after the sensor function’s closing brace. Do not put them inside that function.

bluetooth.onBluetoothConnected(function () {
    btConnected = true
})

bluetooth.onBluetoothDisconnected(function () {
    btConnected = false
    stickStatus = "UNKNOWN"
})

An event runs when the connection changes. It does not belong inside forever.

Read a fresh echo in forever

In MakeCode · JavaScript, then Blocks

forever repeats. Each repeat must read the sensor again before making a decision.

Add this short repeating loop. Choose Blocks and trace the function call followed by the pause.

Check: forever reads a fresh echo and pauses for 500 ms. Keep later additions between these two instructions.

Help if you get stuck

Use the function call that returns a number. Keep the separate purple function definition outside forever.

Add this whole forever at the bottom, outside the other stacks. There must be only one forever.

basic.forever(function () {
    echoTime = readUltrasonicDistance()
    basic.pause(500)
})

The function definition is the recipe. This function call runs that recipe and saves its answer in echoTime.

Build the failed-reading branch first

In MakeCode · JavaScript, then Blocks

An unusable echo must choose UNKNOWN. This test also catches 0 when no echo arrives.

Insert this if/else between the read and the pause. Choose Blocks and inspect the failed-reading branch.

Check: The first then sets 0 and UNKNOWN and shows ?. Its else is empty for the next step.

Help if you get stuck

< means less than; > means greater than. OR means either test can select this branch. 0 here marks an unusable distance. It must not be sent as a real measurement.

Inside forever: add below echoTime = readUltrasonicDistance() and above basic.pause(500).

if (echoTime < 116 || echoTime > 23200) {
    distanceCm = 0
    stickStatus = "UNKNOWN"
    basic.showString("?")
} else {
}

|| means OR. A missing echo is 0, so it enters this branch. The 0 is a placeholder, not a measured distance.

Turn echo time into centimetres

In MakeCode · JavaScript, then Blocks

The sound travels out and back. Dividing its echo time by 58 estimates centimetres. Rounding keeps one decimal place.

Put this calculation inside the empty outer else. Choose Blocks and follow the calculation from inside to outside.

Check: The outer else contains set distanceCm to the calculation. An echo of 1177 gives about 20.3 cm.

Help if you get stuck

Build the sockets from the inside outward. For 20.293… cm: ×10 gives 202.93…, round gives 203, then ÷10 gives 20.3. Leave room below this calculation for the near/far check.

Inside the empty else of the echoTime check. Put this line between its opening and closing braces.

distanceCm = Math.round(echoTime / 58 * 10) / 10

Divide by 58 to estimate cm. Multiply by 10, round, then divide by 10 to keep one decimal place.

Help if you get stuck

The outer sending if asks whether Bluetooth is connected. The inner sending if asks whether this reading is UNKNOWN. They do different jobs.

Inside forever: add after the entire sensor if/else and before basic.pause(500). Keep this sender outside both sensor branches.

if (btConnected) {
    if (stickStatus == "UNKNOWN") {
        bluetooth.uartWriteLine(stickStatus)
    } else {
        bluetooth.uartWriteLine(stickStatus)
    }
}

First ask whether Bluetooth is connected. Then ask whether the reading is UNKNOWN. Each reading sends only one line.

Send the chosen word and distance

Code your walking stick

Program your built model

At your built walking-stick model

The sensor measures distance. Your program chooses a display. X means an obstacle is near; a blank display means a valid reading is farther away. A question mark means the reading cannot be used. Later you will add Bluetooth messages so a separate sound page can play the near warning.

Point to the sensor and the micro:bit display.

Check: You can point to the input and the output.

Help if you get stuck

Keep the model on its table. This guide starts with the model already built.

Wait half a second

In MakeCode · forever, below the whole if block

Walking-stick programming guide

Start with the built model and its existing checked MakeCode sensor project.
No hardware-specific walking-stick source was found in the supplied packs.
The source references mention micro:bit and an ultrasonic sensor, without exact model, pins or sensor error behavior.

WalkingStick_Warning_Reference.ts is a reference function only. It has no sensor adapter or forever loop. It cannot be flashed by itself. Keep your existing extension, pins, centimetre reading and documented validity check.
WalkingStick_Trials.csv is a blank 12-row trial sheet. Never substitute sample readings for actual observations.

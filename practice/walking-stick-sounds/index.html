Connect in Chrome
  1. Use Chrome on a laptop or an Android device with Bluetooth turned on.
  2. Upload your MakeCode Bluetooth UART program to the micro:bit. Follow the coding guide's connection settings.
  3. Click Connect micro:bit. Choose the device named BBC micro:bit.
  4. Click Enable sound. Test the buttons before using sensor readings.

Chrome on iPhone or iPad does not provide this Web Bluetooth connection. School policies or a disabled Bluetooth adapter can also block it.

If the device connects but sends nothing, check start UART service and UART write line in the program. After uploading a new program, disconnect and connect again.

Try without a micro:bit

This demo sends made-up messages inside the page. It does not test Bluetooth or your sensor.

The demo repeats its selected message every half second. Stop messages to see the three-second timeout.

What students program

Send exactly one of these lines after each fresh decision, about every half second while connected.

Micro:bit messagePage response
NEARShow “Obstacle near” and play the selected warning when sound is enabled.
FARShow “Farther reading reported” and stop the warning.
UNKNOWNShow “Reading unknown” and stop the warning.

If messages stop for more than three seconds, the page stops the warning and shows “No recent message”. A connection alone is not a sensor test.
